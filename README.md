# Pryscan privacy policy

The published copy of the privacy policy for the Pryscan iOS app, served
at <https://mpmogale.github.io/pryscan-privacy/>.

This repository is public **only** so that GitHub Pages can serve it; the
app itself lives in a private repository. `index.md` is a copy of
`PRIVACY.md` there — edit that one first, then bring the change here, so
the policy the app ships against and the policy the store links to cannot
disagree.
